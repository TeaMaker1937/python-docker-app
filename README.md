## Описание

Минимальное веб-приложение на Flask, отдающее JSON через HTTP.  
Контейнеризировано с помощью Docker + docker-compose.

## Эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Главная — приветствие |
| GET | `/health` | Health check (HTTP 200) |
| GET | `/info` | Информация о приложении |

## Запуск

```bash
docker compose up -d
curl -i localhost:5000
curl -i localhost:5000/health
